# dotfiles

A repo for my config in case my house burns down and or my laptop fails.
Probably a bit out of date at any moment.

**Workflows**
- [Commit Signing](https://developer.1password.com/docs/ssh/git-commit-signing/)
- **iTerm2** 
  - General > Settings > Load settings from a custom folder > dotfiles repo
  - Revert changes in git, then restart iTerm2
